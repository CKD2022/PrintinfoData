免费部署到 GitHub Pages
创建 GitHub 仓库
登录 GitHub，点击右上角 “+” → “New repository”，仓库名比如 myblog，选择 Public，不要勾选任何初始化文件，点 Create。

推送本地项目到 GitHub
回到 PrintinfoData/ 根目录，依次执行：

bash
git init
git add .
git commit -m "发布我的静态博客"
git branch -M main
git remote add origin git@github.com:ckd2002/PrintinfoData.git
git push -u origin main
（没有配置 SSH 的话，用 https://github.com/ckd2002/PrintinfoData.git）

开启 Pages 服务

在仓库页面点击 Settings → 左侧 Pages

Source 选择 Deploy from a branch

Branch 选 main，文件夹选 /docs，点击 Save

等待一两分钟，上方会显示你的网址：https://你的用户名.github.io/myblog/

打开那个网址，你的静态博客就上线了！
以后写了新文章，只需：

把 .md 文件放进 posts/

运行 python build.py

提交并推送：git add . && git commit -m "新文章" && git push
